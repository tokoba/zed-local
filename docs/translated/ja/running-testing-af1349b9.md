# 実行とテスト

このセクションでは、Zed 内でコードを実行・テストし、エディタから離れることなく問題をデバッグできます。

## このセクションでできること

- **[Terminal](./terminal.md)**: Zed に組み込まれたターミナルエミュレータです。複数のターミナルを開いたり、シェルをカスタマイズしたり、エディタと連携したりできます。タスクやコマンドはここで実行されます。

- **[Tasks](./tasks.md)**: 現在のファイル、選択範囲、シンボルなどのエディタコンテキストにアクセスできるシェルコマンドを定義・実行できます。タスクを使って、ビルド、lint、スクリプトの実行、その他の繰り返し可能なワークフローを実行します。

- **[Debugger](./debugger.md)**: Zed に組み込まれたデバッガを使って、ブレークポイントの設定、ステップ実行、変数の検査ができます。Debug Adapter Protocol を通じて、C、C++、Go、JavaScript、Python、Rust、TypeScript などに対応しています。

- **[REPL](./repl.md)**: Jupyter カーネルを使ってコードを対話的に実行できます。選択範囲またはセルを実行し、その結果をインラインで確認できます。Python、TypeScript (Deno)、R、Julia などのサポートされている言語で便利です。

## クイックスタート

**ターミナルを開く**: ターミナルパネルを切り替えるには `` Ctrl+` `` を押し、新しいターミナルを開くには `Ctrl+~` を押します。

**コマンドを実行する**: `Cmd+Shift+R` (macOS) または `Ctrl+Shift+R` (Linux/Windows) を押してタスクピッカーを開き、任意のシェルコマンドを入力します。

**デバッグを開始する**: `Cmd+Shift+D` (macOS) または `Ctrl+Shift+D` (Linux/Windows) を押してデバッグパネルを開き、デバッグ構成を選択します。

**コードを対話的に実行する**: Python または TypeScript ファイル内でコードを選択し、`Ctrl+Shift+Enter` を押して REPL セッションで実行します。
