# Zed をアップデートする

Zed は自動的に最新の状態を保つように設計されています。この挙動は設定でいつでも変更できます。

## 自動アップデート

デフォルトでは、Zed はアップデートを確認し、次にアプリを再起動したときに自動的にインストールします。追加の操作をしなくても、常に最新バージョンを使用できます。

アップデートが利用可能な場合、Zed はバックグラウンドでそれをダウンロードし、再起動時に適用します。

## 現在のバージョンを確認する方法

使用中の Zed のバージョンを確認するには、次の手順を実行します:

Command Palette（macOS では Cmd+Shift+P、Linux/Windows では Ctrl+Shift+P）を開きます。

`zed: about` と入力して選択します。バージョン情報が表示されたモーダルが開きます。

## アップデートの動作を制御する方法

自動アップデートをオフにしたい場合は、Settings Editor（Cmd ,）を開き、General Settings の下にある `Auto Update` を探します。
