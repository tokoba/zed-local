# サブスクリプション

Zed がホストするモデルは、Zed Pro または Zed Business のサブスクリプションとして提供されています。

> Zed のサブスクリプションがなくても、[独自の API キー](./llm-providers.md)や[外部エージェント](./external-agents.md)を利用できます。

サブスクリプション提供の各側面については、次のページを参照してください。

- [モデル](./models.md): Zed のサブスクリプションで提供されるモデルの概要。

- [プランと利用量](./plans-and-usage.md): Zed のプランと、利用量の測定方法の概要。

- [請求](./billing.md): 請求ポリシーおよび手順、各種請求設定の表示・更新方法。
