# 連絡先とプライベート通話 {#contacts}

プライベート通話は、チャンネルの外でアドホックなコラボレーションセッションを行うための機能です。連絡先をリストに追加し、1人または複数人と通話を開始できます。

## 連絡先の追加

1. コラボレーションパネルで、`Contacts` セクションの横にある `+` ボタンをクリックします。
1. 連絡先をその GitHub ハンドルで検索します。\
   *注: 連絡先は、GitHub 認証のサインインフローを完了した既存の Zed ユーザーである必要があります。*
1. 連絡先に通知が送信されます。
   相手が承諾すると、互いの連絡先リストにお互いが表示されるようになります。

## プライベート通話

プライベート通話を開始するには:

1. コラボレーションパネルで、オンラインの連絡先の名前の横にある `...` メニューをクリックします。
1. `Call <username>` をクリックします。

プライベート通話を開始した後は、コラボレーションパネルでオンラインの連絡先の名前をクリックすることで、他の連絡先を通話に追加できます。

---

*プライベート通話は [チャンネル](./channels.md) と同様に動作しますが、チャンネルノートなどのチャンネル固有の機能は利用できません。*
