# コマンドパレット

コマンドパレットは、Zed でアクションにアクセスするための主な方法です。そのキーバインドは、最初に覚えるべきショートカットのひとつです: {#kb command_palette::Toggle}.

![開いたコマンドパレット](https://zed.dev/img/features/command-palette.jpg)

試してみるには、コマンドパレットを開いて `new file` と入力します。コマンドリストは `workspace: new file` に絞り込まれるはずです。Return キーを押して新しいバッファを作成します。

説明の中に `zed: ...` や `editor: ...` などの形式のコマンドが出てきたら、それらはコマンドパレットで実行する必要があることを意味します。
