# アウトラインパネル

モーダルのアウトライン（`cmd-shift-o`）に加えて、Zed にはアウトラインパネルも用意されています。アウトラインパネルは、`cmd-shift-b`（コマンドパレットから `outline panel: toggle focus` を実行）で表示するか、ステータスバーの `Outline Panel` ボタンをクリックして表示できます。

「シングルトン」バッファ（つまり、タブ上で 1 つのファイルだけを開いている状態）を表示している場合、アウトラインパネルはアウトラインモーダルと同様に動作し、現在のバッファ内のシンボルのアウトラインを表示します。各シンボルのエントリには、シンボル名とともに、その種類を示すプレフィックス（"struct"、"fn"、"mod"、"impl" など）が表示されるため、今見ているものがどのような種類のシンボルかをすばやく判別できます。エントリをクリックすると、ファイル内の対応するセクションにジャンプできます。また、アウトラインビューは、ファイル内の現在のカーソル位置に対応するセクションが表示されるよう、自動的にスクロールします。

![シングルトンバッファでアウトラインパネルを使用している例](https://zed.dev/img/outline-panel/singleton.png)

## マルチバッファでの使い方

アウトラインパネルは、マルチバッファと組み合わせて使用すると真価を発揮します。以下に、その汎用性の例をいくつか示します。

### プロジェクト検索結果

プロジェクト全体の検索結果を俯瞰できます。

![プロジェクト検索マルチバッファでアウトラインパネルを使用している例](https://zed.dev/img/outline-panel/project-search.png)

### プロジェクト診断

言語サーバーから報告されるすべてのエラーと警告の概要を表示します。

![プロジェクト診断マルチバッファを表示しながらアウトラインパネルを使用している例](https://zed.dev/img/outline-panel/project-diagnostics.png)

### すべての参照を検索

`editor: find all references` アクションを使用しているときに、すべての参照間をすばやくナビゲートできます。

![`find all references` マルチバッファを表示しながらアウトラインパネルを使用している例](https://zed.dev/img/outline-panel/find-all-references.png)

アウトラインビューは、コードの特定の箇所へすばやく移動するための優れた手段を提供し、マルチバッファで大きな結果セットを扱う場合でも、作業中のコンテキストを維持するのに役立ちます。
