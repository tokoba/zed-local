# Windows での Zed

## Zed のインストール

最新の安定版ビルドは [ダウンロードページ](https://zed.dev/download) から入手できます。プレビュービルドをダウンロードしたい場合は、その [リリースページ](https://zed.dev/releases/preview) で見つけることができます。最初に手動インストールを行った後は、Zed が定期的に更新の有無を確認します。

Zed をソースコードからビルドすることもできます。手順については [これらのドキュメント](https://zed.dev/docs/development/windows) を参照してください。

### パッケージマネージャー

また、winget を使って Zed をインストールすることもできます:

```sh
winget install -e --id ZedIndustries.Zed
```

## アンインストール

- インストーラーからインストールした場合: `Settings` → `Apps` → `Installed apps` を開き、Zed を検索して「Uninstall」をクリックします。
- ソースからビルドした場合: 作成したビルド出力ディレクトリ (例: target/install フォルダー) を削除します。

設定と拡張機能はユーザープロファイル内に保存されています。アンインストール時に、それらを保持するか削除するかを選択できます。

## リモート開発 (SSH)

Zed は Windows 上で、SSH と WSL の両方を通じたリモート開発をサポートしています。SSH 経由でリモートサーバーに接続したり、WSL ディストリビューション内のファイルを Zed から直接操作できます。

SSH の設定、WSL のセットアップ、トラブルシューティングを含むリモート開発機能の設定および使用方法の詳細な手順については、[リモート開発のドキュメント](./remote-development.md) を参照してください。

## トラブルシューティング

### Zed が起動しない、または空白のウィンドウが表示される

- お使いのハードウェアおよび OS バージョンが Zed と互換性があることを確認してください。詳しくは [インストールガイド](./installation.md) を参照してください。
- GPU ベンダー (Intel/AMD/NVIDIA/Qualcomm) から GPU ドライバーを更新してください。
- Windows でハードウェアアクセラレーションが有効になっており、サードパーティ製ソフトウェアによってブロックされていないことを確認してください。
- 拡張機能やカスタム設定なしで Zed を起動し、競合を切り分けてみてください。

### ターミナルの問題

有効化スクリプトが実行されない場合は、最新版にアップデートし、シェルのプロファイルファイルが早期に終了していないことを確認してください。Git の操作を行う場合は、Git Bash または PowerShell が利用可能であり、PATH に含まれていることを確認してください。

### SSH リモート接続の問題

資格情報の入力を求められた場合は、グラフィカルな askpass ダイアログを使用してください。表示されない場合は、資格情報マネージャーの競合がないか、およびターミナルによって GUI のプロンプトがブロックされていないかを確認してください。

### グラフィックスの問題

#### Zed が起動しない / パフォーマンスが低下している

Zed を実行するには、DirectX 11 に対応した GPU が必要です。Zed が起動しない場合は、GPU が最小要件を満たしていない可能性があります。

GPU が DirectX 11 をサポートしているか確認するには、次のコマンドを実行してください。

```
dxdiag
```

これにより DirectX 診断ツールが開き、`System` → `System Information` → `DirectX Version` の下に GPU がサポートしている DirectX のバージョンが表示されます。

Zed を仮想マシン内で実行している場合、VM が提供するエミュレートされたアダプターが使用されます。この環境でも Zed は動作しますが、パフォーマンスが低下する場合があります。
