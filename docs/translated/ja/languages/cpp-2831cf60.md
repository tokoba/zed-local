# C++

Zed では C++ をネイティブにサポートしています。

- Tree-sitter: [tree-sitter/tree-sitter-cpp](https://github.com/tree-sitter/tree-sitter-cpp)
- 言語サーバー: [clangd/clangd](https://github.com/clangd/clangd)

## バイナリ

Zed が使用する `clangd` バイナリを設定できます。

デフォルトでは、Zed は `$PATH` から `clangd` を探してそれを使用しようとします。そのバイナリの実行に成功した場合は、それが使用されます。そうでない場合、Zed は独自の `clangd` バージョンをインストールし、それを使用します。

代わりにプレリリース版の `clangd` をインストールしたい場合は、`settings.json` で `pre_release` を `true` に設定することで Zed に指示できます。

```json [settings]
{
  "lsp": {
    "clangd": {
      "fetch": {
        "pre_release": true
      }
    }
  }
}
```

Zed による `clangd` バイナリの検索を無効にしたい場合は、`settings.json` で `ignore_system_version` を `true` に設定できます。

```json [settings]
{
  "lsp": {
    "clangd": {
      "binary": {
        "ignore_system_version": true
      }
    }
  }
}
```

任意の場所にあるバイナリを使用したい場合は、`path` と、必要に応じて `arguments` を指定できます。

```json [settings]
{
  "lsp": {
    "clangd": {
      "binary": {
        "path": "/path/to/clangd",
        "arguments": []
      }
    }
  }
}
```

この `"path"` は絶対パスである必要があります。

## Arguments

clangd には任意の数の引数を渡すことができます。利用可能なオプションの一覧を確認するには、コマンドラインから `clangd --help` を実行してください。たとえば `--function-arg-placeholders=0` を指定すると、補完には関数呼び出し用の丸括弧だけが含まれ、デフォルトの (`--function-arg-placeholders=1`) ではメソッド引数のプレースホルダーも含まれます。

```json [settings]
{
  "lsp": {
    "clangd": {
      "binary": {
        "path": "/path/to/clangd",
        "arguments": ["--function-arg-placeholders=0"]
      }
    }
  }
}
```

## Formatting

デフォルトでは Zed は C++ コードのフォーマットに `clangd` 言語サーバーを使用します。このフォーマッタは `clang-format` CLI ツールと同じです。これを設定するには、`.clang-format` ファイルを追加します。例えば次のようになります。

```yaml
# yaml-language-server: $schema=https://json.schemastore.org/clang-format-21.x.json
---
BasedOnStyle: LLVM
IndentWidth: 4
---
Language: Cpp
# C++ の場合、ポインターを型側に揃えるように強制します。
DerivePointerAlignment: false
PointerAlignment: Left
---
```

利用可能なオプションの一覧については、[Clang-Format Style Options](https://clang.llvm.org/docs/ClangFormatStyleOptions.html) を参照してください。

フォーマットは {#kb editor::Format} や、コマンドパレットからの `editor: format` アクション、または保存時フォーマットを有効にすることで実行できます。

Settings（{#kb zed::OpenSettings}）の Languages > C++ でフォーマットを設定するか、設定ファイルに次を追加します。

```json [settings]
  "languages": {
    "C++": {
      "format_on_save": "on",
      "tab_size": 2
    }
  }
```

## More server configuration

プロジェクトのルートには、追加の設定を行うために `.clangd` ファイルを作成するのが一般的です。

```yaml
# yaml-language-server: $schema=https://json.schemastore.org/clangd.json
CompileFlags:
  Add:
    - "--include-directory=/path/to/include"
Diagnostics:
  MissingIncludes: Strict
  UnusedIncludes: Strict
```

clangd の設定ファイルをより高度に利用する方法については、[公式ページ](https://clangd.llvm.org/config.html) を参照してください。

## Compile Commands

一部のプロジェクトでは、clangd がプロジェクトを正しく解析するために `compile_commands.json` ファイルを必要とします。このファイルには、プロジェクトをどのようにビルドするかを clangd に伝えるコンパイルデータベースが含まれます。

### CMake Compile Commands

CMake を使用している場合は、`CMakeLists.txt` に次の行を追加することで `compile_commands.json` を自動生成できます。

```cmake
set(CMAKE_EXPORT_COMPILE_COMMANDS ON)
```

プロジェクトをビルドすると、CMake はビルドディレクトリに `compile_commands.json` ファイルを生成し、clangd がそれを自動的に検出します。

## Debugging

ネイティブバイナリのデバッグには CodeLLDB または GDB を使用できます。（ビルド処理で C++ コンパイラに `-g` を渡し、生成されるバイナリにデバッグ情報が含まれるようにしてください。）`.zed/debug.json` に追加できるデバッグ構成の例を以下に示します。

- [CodeLLDB configuration documentation](https://github.com/vadimcn/codelldb/blob/master/MANUAL.md#starting-a-new-debug-session)
- [GDB configuration documentation](https://sourceware.org/gdb/current/onlinedocs/gdb.html/Debugger-Adapter-Protocol.html)
  - GDB は少なくとも v14.1 である必要があります

### Build and Debug Binary

```json [debug]
[
  {
    "label": "Debug native binary",
    "build": {
      "command": "make",
      "args": ["-j8"],
      "cwd": "$ZED_WORKTREE_ROOT"
    },
    "program": "$ZED_WORKTREE_ROOT/build/prog",
    "request": "launch",
    "adapter": "CodeLLDB"
  }
]
```

## Protocol Extensions

現在、Zed は次の `clangd` [拡張](https://clangd.llvm.org/extensions) を実装しています。

### Inactive Regions

`#if`、`#ifdef`、`#ifndef` などが偽と評価されることによって非アクティブになるコード部分を、自動的に暗く表示します。

### Switch Between Source and Header Files

対応する C++ ソースファイル（例: `.cpp`）とヘッダーファイル（例: `.h`）の間を切り替えられます。
コマンドパレットから {#action editor::SwitchSourceHeader} コマンドを実行するか、`editor::SwitchSourceHeader` アクションにキーバインドを設定することで利用できます。

```json [keymap]
{
  "context": "Editor",
  "bindings": {
    "alt-enter": "editor::SwitchSourceHeader"
  }
}
```
