# Dart

Dart のサポートは [Dart extension](https://github.com/zed-extensions/dart) によって利用できます。

- Tree-sitter: [UserNobody14/tree-sitter-dart](https://github.com/UserNobody14/tree-sitter-dart)
- 言語サーバー: [dart language-server](https://github.com/dart-lang/sdk)

## 前提条件

Dart SDK をインストールする必要があります。

Dart は [dart.dev/get-dart](https://dart.dev/get-dart) から、または [Flutter Version Management CLI (fvm)](https://fvm.app/documentation/getting-started/installation) 経由でインストールできます。

## 設定

`dart` があなたの PATH に含まれている場合、dart extension に特別な設定は必要ありません:

```sh
which dart
dart --version
```

特定の dart バイナリを使用したい場合や、FVM 経由で dart を使用したい場合は、使用する `dart` バイナリを Zed の settings.jsons ファイルで指定できます:

```json [settings]
{
  "lsp": {
    "dart": {
      "binary": {
        "path": "/opt/homebrew/bin/fvm",
        "arguments": ["dart", "language-server", "--protocol=lsp"]
      }
    }
  }
}
```

### フォーマット

Dart はデフォルトで、非常に保守的な最大行長 (80) を使用します。自動フォーマット時に dart LSP でより長い行の長さを許可したい場合は、次の設定を Zed の settings.json に追加してください:

```json [settings]
{
  "lsp": {
    "dart": {
      "settings": {
        "lineLength": 140
      }
    }
  }
}
```

[dart language-server capabilities](https://github.com/dart-lang/sdk/blob/main/pkg/analysis_server/tool/lsp_spec/README.md) についての詳細は、Dart のドキュメントを参照してください。
