# Bash

Bash のサポートは [Bash extension](https://github.com/zed-extensions/bash) を通じて利用できます。

- Tree-sitter: [tree-sitter/tree-sitter-bash](https://github.com/tree-sitter/tree-sitter-bash)
- 言語サーバー: [bash-lsp/bash-language-server](https://github.com/bash-lsp/bash-language-server)

## 設定

`shellcheck` が利用可能な場合、`bash-language-server` は内部的にそれを使用して診断情報を提供します。

### `shellcheck` のインストール

```sh
brew install shellcheck             # macOS（HomeBrew）
apt-get install shellcheck          # Ubuntu/Debian
pacman -S shellcheck                # ArchLinux
dnf install shellcheck              # Fedora
yum install shellcheck              # CentOS/RHEL
zypper install shellcheck           # openSUSE
choco install shellcheck            # Windows（Chocolatey）
```

そして、パスから利用できることを確認します:

```sh
which shellcheck
shellcheck --version
```

報告される警告やエラーをカスタマイズしたい場合は、`.shellcheckrc` ファイルを作成するだけで済みます。これはプロジェクトのルート、またはホームディレクトリ（`~/.shellcheckrc`）に作成できます。詳細については [shellcheck documentation](https://github.com/koalaman/shellcheck/wiki/Ignore#ignoring-one-or-more-types-of-errors-forever) を参照してください。
