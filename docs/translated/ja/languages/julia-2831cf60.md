# Julia

Zed における Julia の言語サポートは、コミュニティによってメンテナンスされている [Julia extension](https://github.com/JuliaEditorSupport/zed-julia) によって提供されています。  
問題の報告先: <https://github.com/JuliaEditorSupport/zed-julia/issues>

- Tree-sitter: [tree-sitter/tree-sitter-julia](https://github.com/tree-sitter/tree-sitter-julia)
- 言語サーバー: [julia-vscode/LanguageServer.jl](https://github.com/julia-vscode/LanguageServer.jl)
