# SQL

SQL ファイルは [SQL Extension](https://github.com/zed-extensions/sql) によって処理されます。

- Tree-sitter: [nervenes/tree-sitter-sql](https://github.com/nervenes/tree-sitter-sql)

### フォーマット

Zed は [`sql-formatter`](https://github.com/sql-formatter-org/sql-formatter) のような外部ツールを使用した SQL の自動フォーマットをサポートしています。

1. `sql-formatter` をインストールします:

```sh
npm install -g sql-formatter
```

2. `sql-formatter` が PATH から利用可能であることを確認し、バージョンを確認します:

```sh
which sql-formatter
sql-formatter --version
```

3. Settings（{#kb zed::OpenSettings}）の Languages > SQL でフォーマットを設定するか、設定ファイルに次を追加します:

```json [settings]
  "languages": {
    "SQL": {
      "formatter": {
        "external": {
          "command": "sql-formatter",
          "arguments": ["--language", "mysql"]
        }
      }
    }
  },
```

上記の `mysql` を、任意の [SQL Dialect]（`duckdb`、`hive`、`mariadb`、`postgresql`、`redshift`、`snowflake`、`sqlite`、`spark` など）に置き換えてください。

これは Zed のプロジェクト設定（`.zed/settings.json`）か、Zed のユーザー設定（`~/.config/zed/settings.json`）に追加できます。

### 高度なフォーマット

`sql-formatter` は、[sql-formatter の構成オプション](https://github.com/sql-formatter-org/sql-formatter#configuration-options) を指定することで、より細かな制御も行えます。これらを指定するには、プロジェクトに `.sql-formatter.json` ファイルを作成します:

```json
{
  "language": "postgresql",
  "tabWidth": 2,
  "keywordCase": "upper",
  "linesBetweenQueries": 2
}
```

`.sql-formatter.json` ファイルを使用する場合は、簡略化した Zed 設定の構成を使用できます:

```json [settings]
{
  "languages": {
    "SQL": {
      "formatter": {
        "external": {
          "command": "sql-formatter"
        }
      }
    }
  }
}
```
