# Uiua

[Uiua](https://www.uiua.org/) は、シンプルさ、美しさ、そしてタキシットコードに重点を置いた、汎用のスタックベースかつ配列指向のプログラミング言語です。

Uiua のサポートは [Uiua extension](https://github.com/zed-extensions/uiua) を通じて利用できます。

- Tree-sitter: [shnarazk/tree-sitter-uiua](https://github.com/shnarazk/tree-sitter-uiua)
- Language Server: [uiua-lang/uiua](https://github.com/uiua-lang/uiua/)
