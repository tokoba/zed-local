# GLSL

GLSL (OpenGL Shading Language) のサポートは [GLSL Extension](https://github.com/zed-industries/zed/tree/main/extensions/glsl/) を通じて利用できます。

- Tree-sitter: [theHamsta/tree-sitter-glsl](https://github.com/theHamsta/tree-sitter-glsl)
- 言語サーバー: [nolanderc/glsl_analyzer](https://github.com/nolanderc/glsl_analyzer)
