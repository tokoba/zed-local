# Groovy

Zed における Groovy 言語サポートは、コミュニティによってメンテナンスされている [Groovy extension](https://github.com/valentinegb/zed-groovy) によって提供されています。
不具合の報告先: <https://github.com/valentinegb/zed-groovy/issues>

- Tree-sitter: [murtaza64/tree-sitter-groovy](https://github.com/murtaza64/tree-sitter-groovy)
- 言語サーバー: [GroovyLanguageServer/groovy-language-server](https://github.com/GroovyLanguageServer/groovy-language-server)
