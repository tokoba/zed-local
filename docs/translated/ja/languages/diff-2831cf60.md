# Diff

Diff のサポートは Zed にネイティブで用意されています。

- Tree-sitter: [zed-industries/the-mikedavis/tree-sitter-diff](https://github.com/the-mikedavis/tree-sitter-diff)

## 設定

Zed は diff ファイルのフォーマットを試みず、[`remove_trailing_whitespace_on_save`](https://zed.dev/docs/reference/all-settings#remove-trailing-whitespace-on-save) と [`ensure-final-newline-on-save`](https://zed.dev/docs/reference/all-settings#ensure-final-newline-on-save) が false に設定されています。

Zed は `patch` および `diff` 拡張子を持つファイルを自動的に Diff ファイルとして認識します。その他の拡張子を認識させるには、Zed の settings.json の `file_types` にそれらを追加してください:

```json [settings]
  "file_types": {
    "Diff": ["dif"]
  },
```
