# Yarn

[Yarn](https://yarnpkg.com/) は、決定的な依存関係解決とオフラインキャッシュ機能を提供する JavaScript パッケージマネージャーです。

## セットアップ

1. `.yarn/sdks` ディレクトリを生成するために `yarn dlx @yarnpkg/sdks base` を実行します。
2. [LSP initialization options](../reference/all-settings.md#lsp) で、言語サーバー（例: VTSLS）が `.yarn/sdks/typescript/lib` ディレクトリ内の TypeScript SDK を使用するように設定します。実際の設定項目は使用している言語サーバーによって異なります。例えば VTSLS の場合は、[`typescript.tsdk`](https://github.com/yioneko/vtsls/blob/6adfb5d3889ad4b82c5e238446b27ae3ee1e3767/packages/service/configuration.schema.json#L5) を設定します。

設定後は、言語サーバーの機能（Go to Definition、補完、ホバーによるドキュメント表示）が正しく動作するはずです。
