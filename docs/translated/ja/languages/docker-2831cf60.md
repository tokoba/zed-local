# Docker

Zed における `Dockerfile` と `docker-compose.yaml` のサポートは、コミュニティによってメンテナンスされている拡張機能によって提供されています。

## Docker Compose

Zed における Docker `compose.yaml` の言語サポートは [Docker Compose extension](https://github.com/eth0net/zed-docker-compose) によって提供されています。不具合は次に報告してください: <https://github.com/eth0net/zed-docker-compose/issues>。

- 言語サーバー: [microsoft/compose-language-service](https://github.com/microsoft/compose-language-service)

## Dockerfile

Zed における `Dockerfile` の言語サポートは [Dockerfile extension](https://github.com/d1y/dockerfile.zed) によって提供されています。不具合は次に報告してください: <https://github.com/d1y/dockerfile.zed/issues>。

- Tree-sitter: [camdencheek/tree-sitter-dockerfile](https://github.com/camdencheek/tree-sitter-dockerfile)
- 言語サーバー: [rcjsuen/dockerfile-language-server](https://github.com/rcjsuen/dockerfile-language-server)
