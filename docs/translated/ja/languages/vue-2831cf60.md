# Vue

Vue のサポートは [Vue extension](https://github.com/zed-extensions/vue) 経由で利用できます。

- Tree-sitter: [tree-sitter-grammars/tree-sitter-vue](https://github.com/tree-sitter-grammars/tree-sitter-vue)
- 言語サーバー: [vuejs/language-tools](https://github.com/vuejs/language-tools)

## Initialization Options

### TypeScript SDK の場所の指定

デフォルトでは、この拡張機能は `node_modules` ディレクトリを含むプロジェクトで作業していると仮定し、そのディレクトリ内で TypeScript SDK を検索します。

これは常に正しいとは限りません。たとえば Yarn PnP を使用するプロジェクトでは `node_modules` が存在しません。エディタでのサポートについては、[ドキュメント](https://yarnpkg.com/getting-started/editor-sdks) に記載されているアプローチとして `yarn dlx @yarnpkg/sdks` のようなコマンドを実行します。その場合、Zed の設定で次の初期化オプションを指定できます:

```json
{
  "lsp": {
    "vue": {
      "initialization_options": {
        "typescript": {
          "tsdk": ".yarn/sdks/typescript/lib"
        }
      }
    }
  }
}
```

## Settings Options

`lsp.vue.settings` は Vue language server（Volar / [`vuejs/language-tools`](https://github.com/vuejs/language-tools)）にそのまま渡されます。以下の設定はデフォルトで有効になっています:

```json
{
  "lsp": {
    "vue": {
      "settings": {
        // インラインイベントハンドラ内の `$event` パラメータのインレイヒントを表示します。
        "vue.inlayHints.inlineHandlerLeading": true,
        // テンプレートで必須のコンポーネント props が不足している場合にヒントを表示します。
        "vue.inlayHints.missingProps": true,
        // コンポーネントオプションをラップするパターンに対するインレイヒントを表示します。
        "vue.inlayHints.optionsWrapper": true,
        // `v-bind` 省略記法（`:`）に関するインレイヒントを表示します。
        "vue.inlayHints.vBindShorthand": true
      }
    }
  }
}
```

上流の設定構成スキーマは[`こちら`](https://github.com/vuejs/language-tools/blob/ee5041d27940cf6f9a5150635d3b13140a9dff54/extensions/vscode/package.json#L252)で確認できます。

> Note: 一部の設定（例: `vue.editor.focusMode`）は効果がない場合があります。

## Vue で Tailwind CSS Language Server を利用する

Vue ファイルで [Tailwind CSS language server](https://github.com/tailwindlabs/tailwindcss-intellisense/tree/HEAD/packages/tailwindcss-language-server#readme) の全機能（補完、Lint など）を利用するには、`settings.json` に以下を追加して、言語サーバーが CSS クラスをどこから探せばよいかを認識できるように設定する必要があります:

```json [settings]
{
  "lsp": {
    "tailwindcss-language-server": {
      "settings": {
        "includeLanguages": {
          "vue": "html"
        },
        "experimental": {
          "classRegex": [
            "class=\"([^\"]*)\"",
            "class='([^']*)'",
            ":class=\"([^\"]*)\"",
            ":class='([^']*)'"
          ]
        }
      }
    }
  }
}
```

これらの設定により、Vue テンプレートファイル内で Tailwind CSS クラスの補完が有効になります。例:

```vue
<template>
  <!-- 静的な class 属性 -->
  <div class="flex items-center <completion here>">
    <p class="text-lg font-bold <completion here>">Hello World</p>
  </div>

  <!-- 動的な class バインディング -->
  <div
    :class="
      active ? 'bg-blue-500 <completion here>' : 'bg-gray-200 <completion here>'
    "
  >
    Content
  </div>

  <!-- 配列構文 -->
  <div :class="['flex', 'items-center', '<completion here>']">Content</div>

  <!-- オブジェクト構文 -->
  <div
    :class="{
      'flex <completion here>': isFlex,
      'block <completion here>': isBlock,
    }"
  >
    Content
  </div>
</template>
```
