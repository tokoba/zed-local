# Yara

`Yara` 言語の Zed におけるサポートは、[Yara language extension](https://github.com/egibs/yara.zed) によって提供されています。問題があれば <https://github.com/egibs/yara.zed/issues> に報告してください。

- Tree-sitter: [egibs/tree-sitter-yara](https://github.com/egibs/tree-sitter-yara)
- 言語サーバー: [avast/yls](https://github.com/avast/yls)
