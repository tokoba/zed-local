# YAML

Zed は YAML をネイティブにサポートしています。

- Tree-sitter: [zed-industries/tree-sitter-yaml](https://github.com/zed-industries/tree-sitter-yaml)
- 言語サーバー: [redhat-developer/yaml-language-server](https://github.com/redhat-developer/yaml-language-server)

## 設定

`lsp` キーの下にある `yaml-language-server` ブロック内に、Zed の settings.json に追記することで、さまざまな [yaml-language-server の設定](https://github.com/redhat-developer/yaml-language-server?tab=readme-ov-file#language-server-settings) を行えます。

相対パスを使用してカスタム YAML スキーマを設定できます。Zed はパスをプロジェクトルートからの相対パスとして解決します:

```json [settings]
  "lsp": {
    "yaml-language-server": {
      "settings": {
        "yaml": {
          "keyOrdering": true,
          "format": {
            "singleQuote": true
          },
          "schemas": {
              "https://getcomposer.org/schema.json": ["/*"],
              "./schemas/kubernetes.yaml": "k8s/**/*.yaml",
              "~/global-schemas/docker-compose.yaml": "docker-compose*.yml"
          }
        }
      }
    }
  }
```

`./` で始まるパスはワークツリーのルートを基準に解決されます。`~/` で始まるパスはホームディレクトリに展開されます。

注意: 設定キーはネストされている必要があるため、`yaml.keyOrdering` は `{"yaml": { "keyOrdering": true }}` という形になります。

## フォーマット

デフォルトでは、Zed は YAML ファイルのフォーマットに Prettier を使用します。

### Prettier によるフォーマット

Prettier のフォーマット動作はカスタマイズできます。たとえば、YAML ファイルでシングルクォートを使用するには、`.prettierrc` 設定ファイルに次の内容を追加します。

```json
{
  "overrides": [
    {
      "files": ["*.yaml", "*.yml"],
      "options": {
        "singleQuote": false
      }
    }
  ]
}
```

### yaml-language-server によるフォーマット

YAML のフォーマットに Prettier の代わりに `yaml-language-server` を使用するには、Settings ({#kb zed::OpenSettings}) の Languages > YAML で設定するか、settings ファイルに次を追加します。

```json [settings]
  "languages": {
    "YAML": {
      "formatter": "language_server"
    }
  }
```

## スキーマ

デフォルトでは、yaml-language-server は対象の YAML ファイルに対して適切なスキーマを判別し、[Json Schema Store](https://schemastore.org/) から対応する JSON Schema を取得しようとします。

自動検出されたスキーマは、`schemas` 設定キー（上記の例）を使用して上書きするか、YAML ファイルの先頭に modeline コメントとして [インラインスキーマ](https://github.com/redhat-developer/yaml-language-server#using-inlined-schema) の参照を指定することで上書きできます。

```yaml
# yaml-language-server: $schema=https://www.schemastore.org/github-action.json
name: Issue Assignment
on:
  issues:
    types: [opened]
```

必要に応じて、JSON Schema からのスキーマの自動検出および取得を無効にすることもできます。

```json [settings]
  "lsp": {
    "yaml-language-server": {
      "settings": {
        "yaml": {
          "schemaStore": {
            "enable": false
          }
        }
      }
    }
  }
```

## カスタムタグ

yaml-language-server は、実行時に YAML ファイルへカスタムアプリケーション機能を挿入するために使用できる [カスタムタグ](https://github.com/redhat-developer/yaml-language-server#adding-custom-tags) をサポートしています。

たとえば、Amazon CloudFormation の YAML では多数のカスタムタグが使用されています。これらをサポートするには、settings.json に次の設定を追加します。

```json [settings]
  "lsp": {
    "yaml-language-server": {
      "settings": {
        "yaml": {
          "customTags": [
            "!And scalar",
            "!And mapping",
            "!And sequence",
            "!If scalar",
            "!If mapping",
            "!If sequence",
            "!Not scalar",
            "!Not mapping",
            "!Not sequence",
            "!Equals scalar",
            "!Equals mapping",
            "!Equals sequence",
            "!Or scalar",
            "!Or mapping",
            "!Or sequence",
            "!FindInMap scalar",
            "!FindInMap mapping",
            "!FindInMap sequence",
            "!Base64 scalar",
            "!Base64 mapping",
            "!Base64 sequence",
            "!Cidr scalar",
            "!Cidr mapping",
            "!Cidr sequence",
            "!Ref scalar",
            "!Ref mapping",
            "!Ref sequence",
            "!Sub scalar",
            "!Sub mapping",
            "!Sub sequence",
            "!GetAtt scalar",
            "!GetAtt mapping",
            "!GetAtt sequence",
            "!GetAZs scalar",
            "!GetAZs mapping",
            "!GetAZs sequence",
            "!ImportValue scalar",
            "!ImportValue mapping",
            "!ImportValue sequence",
            "!Select scalar",
            "!Select mapping",
            "!Select sequence",
            "!Split scalar",
            "!Split mapping",
            "!Split sequence",
            "!Join scalar",
            "!Join mapping",
            "!Join sequence",
            "!Condition scalar",
            "!Condition mapping",
            "!Condition sequence"
          ]
        }
      }
    }
  }
```
