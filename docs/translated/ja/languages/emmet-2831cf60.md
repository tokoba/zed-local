# Emmet

Emmet のサポートは [Emmet extension](https://github.com/zed-extensions/emmet) を通じて利用できます。

[Emmet](https://emmet.io/) は、HTML と CSS のワークフローを大幅に改善できる Web 開発者向けツールキットです。

- 言語サーバー: [olrtg/emmet-language-server](https://github.com/olrtg/emmet-language-server)
