# JSON

Zed では JSON がネイティブにサポートされています。

- Tree-sitter: [tree-sitter/tree-sitter-json](https://github.com/tree-sitter/tree-sitter-json)
- 言語サーバー: [zed-industries/json-language-server](https://github.com/zed-industries/json-language-server)

## JSONC

Zed は JSON のスーパーセットである JSONC もサポートしており、JSON ファイル内で行コメント（`//`）を使用できます。
これらのファイルを編集しているときは、`cmd-/`（macOS）または `ctrl-/`（Linux）を使って、現在の行または選択範囲のコメントを切り替えることができます。

## JSONC の Prettier によるフォーマット

`Format Document` を使用する際に `*.jsonc` 拡張子のファイルを使っている場合、または `format_on_save` を有効にしている場合、Zed はフォーマッタとして Prettier を呼び出します。Prettier には、`jsonc` 拡張子のファイルに末尾のカンマを追加してしまう[未解決の issue](https://github.com/prettier/prettier/issues/15956)があります。`.json` 拡張子を持つ JSONC ファイルは影響を受けません。

この動作を回避するには、次の内容を `.prettierrc` 設定ファイルに追加してください:

```json
{
  "overrides": [
    {
      "files": ["*.jsonc"],
      "options": {
        "parser": "json",
        "trailingComma": "none"
      }
    }
  ]
}
```

## JSON 言語サーバー

Zed は標準で `package.json` および `tsconfig.json` ファイルの JSON Schema 検証に対応していますが、`json-language-server` を使用すると、プロジェクト内のファイルにある JSON Schema 定義や、[JSON Schema Store](https://www.schemastore.org) などの公開 URL から取得した JSON Schema を使って JSON を検証できます。

### インラインでのスキーマ指定

JSON ファイル内でスキーマをインライン指定するには、JSON Schema ファイルを指すトップレベルキー `$schema` を追加します。

例えば、[lua-language-server](https://github.com/LuaLS/lua-language-server/) で使用する `.luarc.json` は次のようになります:

```json
{
  "$schema": "https://raw.githubusercontent.com/sumneko/vscode-lua/master/setting/schema.json",
  "runtime.version": "Lua 5.4"
}
```

### 設定によるスキーマ指定

言語サーバーの設定で相対パスを使用して、JSON Schema をファイルパスに関連付けることができます。Zed はパスをプロジェクトのルートからの相対パスとして解決します:

```json [settings]
"lsp": {
  "json-language-server": {
    "settings": {
      "json": {
        "schemas": [
          {
            "fileMatch": ["config/*.json"],
            "url": "./schemas/custom-schema.json"
          },
          {
            "fileMatch": ["*.config.json"],
            "url": "~/global-schemas/shared.json"
          },
          {
            "fileMatch": ["*/*.luarc.json"],
            "url": "https://raw.githubusercontent.com/sumneko/vscode-lua/master/setting/schema.json"
          }
        ]
      }
    }
  }
}
```

`./` で始まるパスはワークツリーのルートを基準として解決されます。`~/` で始まるパスはホームディレクトリに展開されます。
