# R

R のサポートは、複数の R 向け Zed 拡張機能を通じて利用できます。

- [ocsmit/zed-r](https://github.com/ocsmit/zed-r)

  - Tree-sitter: [r-lib/tree-sitter-r](https://github.com/r-lib/tree-sitter-r)
  - 言語サーバー: [REditorSupport/languageserver](https://github.com/REditorSupport/languageserver)

- [posit-dev/air](https://github.com/posit-dev/air/tree/main/editors/zed)
  - フォーマッタ: [posit-dev/air](https://posit-dev.github.io/air/)

## インストール

1. [R をダウンロードしてインストールする](https://cloud.r-project.org/)。
2. R パッケージ `languageserver` と `lintr` をインストールします:

```R
install.packages("languageserver")
install.packages("lintr")
```

3. 基本的な R 言語サポート（シンタックスハイライト、Tree-sitter サポート）および [REditorSupport/languageserver](https://github.com/REditorSupport/languageserver) のサポートのために、Zed の拡張機能マネージャーから [R](https://github.com/ocsmit/zed-r) 拡張機能をインストールします。

4. Air 経由で R コードをフォーマットするために、Zed の拡張機能マネージャーから [Air](https://posit-dev.github.io/air/) 拡張機能をインストールします。

## Lint

`REditorSupport/languageserver` には、リンターとして [r-lib/lintr](https://github.com/r-lib/lintr) へのサポートが同梱されています。これは、プロジェクト内（またはグローバルデフォルトとしてホームディレクトリ）に `.lintr` を配置して利用することで設定できます。

```r
linters: linters_with_defaults(
    line_length_linter(120),
    commented_code_linter = NULL
  )
exclusions: list(
    "inst/doc/creating_linters.R" = 1,
    "inst/example/bad.R",
    "tests/testthat/exclusions-test"
  )
```

または、何も Lint されないように除外するには、

```r
exclusions: list(".")
```

利用可能なオプションの完全な一覧については、[Using lintr](https://lintr.r-lib.org/articles/lintr.html) を参照してください。

## フォーマット

### Air

[Air](https://posit-dev.github.io/air/) は、保存時自動フォーマット（format-on-save）への対応を含め、R のコードフォーマットを提供します。[Zed 向け Air ドキュメント](https://posit-dev.github.io/air/editor-zed.html)には、Zed で Air を実行するための最新の推奨事項が記載されています。

Zed での一般的な R 言語認識のための [ocsmit/zed-r](https://github.com/ocsmit/zed-r) 拡張機能と、[Air](https://posit-dev.github.io/air/) 拡張機能の両方がインストールされていることを確認してください。

Settings ({#kb zed::OpenSettings}) の Languages > R で言語サーバーを構成するか、設定ファイルに次を追加します。

```json [settings]
{
  "languages": {
    "R": {
      "language_servers": ["air"]
    }
  }
}
```

`REditorSupport/languageserver` の `"r_language_server"` を使用している場合でも、フォーマットには Air を使用したいときは、Settings ({#kb zed::OpenSettings}) の Languages > R で次のように設定するか、設定ファイルに次を追加します。

```json [settings]
{
  "languages": {
    "R": {
      "language_servers": ["air", "r_language_server"],
      "use_on_type_format": false
    }
  }
}
```

このリストでは `"air"` を先頭に配置する必要がある点に注意してください。そうしないと、`"r_language_server"` 経由で [r-lib/styler](https://github.com/r-lib/styler) が呼び出されます。

`"r_language_server"` は、Air のフォーマット規則とは異なるオンタイプフォーマットを提供します。これを完全に避けて Air に R ファイルのフォーマットを全面的に任せるには、上記のように `"use_on_type_format": false` も設定してください。

#### Air の設定

Air は、プロジェクトのルートフォルダーに配置した `air.toml` ファイルを通じて、最小限の設定が可能です。

```toml
[format]
line-width = 80
indent-width = 2
```

詳細については、[configuration](https://posit-dev.github.io/air/configuration.html) に関する Air のドキュメントを参照してください。

### Styler

`REditorSupport/languageserver` には、フォーマッタとして [r-lib/styler](https://github.com/r-lib/styler) へのサポートが同梱されています。その動作のカスタマイズ方法については、[Customizing Styler](https://cran.r-project.org/web/packages/styler/vignettes/customizing_styler.html) を参照してください。
