# XML

XML サポートは [XML extension](https://github.com/sweetppro/zed-xml/) を通じて利用できます。

- Tree-sitter: [tree-sitter-grammars/tree-sitter-xml](https://github.com/tree-sitter-grammars/tree-sitter-xml)

## 設定

追加のファイル拡張子があり、それらが自動的に XML として認識されない場合は、Zed の設定の [file_types](../reference/all-settings.md#file-types) に追加してください:

```json [settings]
  "file_types": {
    "XML": ["rdf", "gpx", "kml"]
  }
```
