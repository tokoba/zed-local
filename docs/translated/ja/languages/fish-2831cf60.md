# Fish

Zed における Fish 言語のサポートは、コミュニティがメンテナンスしている [Fish extension](https://github.com/hasit/zed-fish) によって提供されています。  
不具合の報告先: <https://github.com/hasit/zed-fish/issues>

- Tree-sitter: [ram02z/tree-sitter-fish](https://github.com/ram02z/tree-sitter-fish)

### フォーマット

Zed は、fish に同梱されている [`fish_indent`](https://fishshell.com/docs/current/cmds/fish_indent.html) のような外部ツールを使って、fish のコードを自動整形することをサポートしています。

1. `fish_indent` がパス上で利用可能であることを確認し、バージョンをチェックします:

```sh
which fish_indent
fish_indent --version
```

2. Zed が `fish_indent` を使って fish のコードを自動整形するように設定します:

```json [settings]
  "languages": {
    "Fish": {
      "formatter": {
        "external": {
          "command": "fish_indent"
        }
      }
    }
  },
```
