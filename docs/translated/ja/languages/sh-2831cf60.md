# シェルスクリプト

シェルスクリプト（bash、zsh、dash、sh）は Zed でネイティブにサポートされています。

- Tree-sitter: [tree-sitter/tree-sitter-bash](https://github.com/tree-sitter/tree-sitter-bash)

## 設定

設定は Settings ({#kb zed::OpenSettings}) の Languages > Shell Script で行うか、設定ファイルに次を追加します:

```json [settings]
  "languages": {
    "Shell Script": {
      "tab_size": 2,
      "hard_tabs": false
    }
  }
```

### フォーマット

Zed は [`shfmt`](https://github.com/mvdan/sh) のような外部ツールを使用したシェルスクリプトの自動フォーマットをサポートしています。

1. `shfmt` をインストールします:

```sh
brew install shfmt            # macOS（Homebrew）
sudo apt-get install shfmt    # Debian/Ubuntu
dnf install shfmt             # Fedora
yum install shfmt             # Red Hat
pacman -Sy shfmt              # Arch Linux
choco install shfmt           # Windows（Chocolatey）
```

2. `shfmt` がパス上で利用可能であることを確認し、バージョンを確認します:

```sh
which shfmt
shfmt --version
```

3. フォーマット設定を Settings ({#kb zed::OpenSettings}) の Languages > Shell Script で行うか、設定ファイルに次を追加します:

```json [settings]
  "languages": {
    "Shell Script": {
      "format_on_save": "on",
      "formatter": {
        "external": {
          "command": "shfmt",
          // お好みの tab_size に合わせて `--indent 2` を変更します
          "arguments": ["--filename", "{buffer_path}", "--indent", "2"]
        }
      }
    }
  }
```
