# Lua

Lua のサポートは [Lua extension](https://github.com/zed-extensions/lua) を通じて利用できます。

- Tree-sitter: [tree-sitter-grammars/tree-sitter-lua](https://github.com/tree-sitter-grammars/tree-sitter-lua)
- 言語サーバー: [LuaLS/lua-language-server](https://github.com/LuaLS/lua-language-server)

## luarc.json

LuaLS を設定するには、プロジェクトのルートに `.luarc.json` ファイルを作成できます。

```json
{
  "$schema": "https://raw.githubusercontent.com/LuaLS/vscode-lua/master/setting/schema.json",
  "runtime.version": "Lua 5.4",
  "format.enable": true,
  "workspace.library": ["../somedir/library"]
}
```

利用可能なすべての設定オプションについては [LuaLS Settings Documentation](https://luals.github.io/wiki/settings/) を参照してください。また、このファイルを Zed で編集すると、利用可能な設定オプションは自動補完されます（例: `runtime.version` には `"Lua 5.1"`、`"Lua 5.2"`、`"Lua 5.3"`、`"Lua 5.4"`、`"LuaJIT"` が許可される値として表示されます）。VS Code から設定オプションをインポートする場合は、`Lua.` プレフィックスを削除することに注意してください（例: `Lua.runtime.version` ではなく `runtime.version`）。

### LuaCATS Definitions

LuaLS は LuaCATS（Lua Comment and Type System）定義を利用することで、LSP の補完候補や型検証を強化できます。これらの定義は多くの一般的な Lua ライブラリ向けに提供されており、それらを含むローカルパスを `luarc.json` の `workspace.library` で指定できます。定義をプロジェクトと同じ親ディレクトリにチェックアウトしている場合（`../playdate-luacats`、`../love2d` など）、相対パスで指定できます。あるいは、各 LuaCATS 定義リポジトリごとにプロジェクト内にサブモジュールを作成することもできます。

### LÖVE (Love2D) {#love2d}

Zed で [LÖVE (Love2D)](https://love2d.org/) を使用するには、プロジェクトの親フォルダー内に `love2d-luacats` というフォルダーを作成し、その中に [LuaCATS/love2d](https://github.com/LuaCATS/love2d) をチェックアウトします:

```sh
cd .. && git clone https://github.com/LuaCATS/love2d love2d-luacats
```

次に、`.luarc.json` では次のようにします:

```
{
  "$schema": "https://raw.githubusercontent.com/LuaLS/vscode-lua/master/setting/schema.json",
  "runtime.version": "Lua 5.4",
  "workspace.library": ["../love2d-luacats"],
  "runtime.special": {
    "love.filesystem.load": "loadfile"
  }
}
```

### PlaydateSDK

Zed で [Playdate Lua SDK](https://play.date/dev/) を使用するには、[playdate-luacats](https://github.com/notpeter/playdate-luacats) をプロジェクトの親フォルダーにチェックアウトします:

```sh
cd .. && git clone https://github.com/notpeter/playdate-luacats
```

次に、`.luarc.json` では次のようにします:

```json
{
  "$schema": "https://raw.githubusercontent.com/LuaLS/vscode-lua/master/setting/schema.json",
  "runtime.version": "Lua 5.4",
  "runtime.nonstandardSymbol": [
    "+=",
    "-=",
    "*=",
    "/=",
    "//=",
    "%=",
    "<<=",
    ">>=",
    "&=",
    "|=",
    "^="
  ],
  "diagnostics.severity": { "duplicate-set-field": "Hint" },
  "diagnostics.globals": ["import"],
  "workspace.library": ["../playdate-luacats"],
  "format.defaultConfig": {
    "indent_style": "space",
    "indent_size": "4"
  },
  "format.enable": true,
  "runtime.builtin": { "io": "disable", "os": "disable", "package": "disable" }
}
```

### インライン ヒント

Zed で LuaLS の [Inlay Hints](../configuring-languages.md#inlay-hints) を有効にするには

1. Settings ({#kb zed::OpenSettings}) の Languages > Lua でインライン ヒントを設定するか、設定ファイルに次を追加します:

```json [settings]
{
  "languages": {
    "Lua": {
      "inlay_hints": {
        "enabled": true,
        "show_type_hints": true,
        "show_parameter_hints": true,
        "show_other_hints": true
      }
    }
  }
}
```

2. `.luarc.json` に `"hint.enable": true` を追加します。

## フォーマット

### LuaLS によるフォーマット

LuaLS（[CppCXY/EmmyLuaCodeStyle](https://github.com/CppCXY/EmmyLuaCodeStyle) によって提供）で自動フォーマットを有効にするには、`.luarc.json` に `"format.enable": true` が設定されていることを確認します:

```json
{
  "$schema": "https://raw.githubusercontent.com/sumneko/vscode-lua/master/setting/schema.json",
  "format.enable": true
}
```

フォーマットは Settings ({#kb zed::OpenSettings}) の Languages > Lua で設定するか、設定ファイルに次を追加します:

```json [settings]
{
  "languages": {
    "Lua": {
      "format_on_save": "on",
      "formatter": "language_server"
    }
  }
}
```

さまざまな EmmyLuaCodeStyle のスタイルオプションは `.editorconfig` でカスタマイズできます。利用可能なオプションについては [lua.template.editorconfig](https://github.com/CppCXY/EmmyLuaCodeStyle/blob/master/lua.template.editorconfig) を参照してください。

### StyLua によるフォーマット

代わりに、自動フォーマットに [StyLua](https://github.com/JohnnyMorganz/StyLua) を使用することもできます:

1. [StyLua](https://github.com/JohnnyMorganz/StyLua) をインストールします: `brew install stylua` または `cargo install stylua --features lua52,lua53,lua54,luau,luajit`（不要な Lua のバージョンは削除して構いません）。
2. Settings ({#kb zed::OpenSettings}) の Languages > Lua でフォーマットを設定するか、設定ファイルに次を追加します:

```json [settings]
{
  "languages": {
    "Lua": {
      "format_on_save": "on",
      "formatter": {
        "external": {
          "command": "stylua",
          "arguments": [
            "--syntax=Lua54",
            "--respect-ignores",
            "--stdin-filepath",
            "{buffer_path}",
            "-"
          ]
        }
      }
    }
  }
}
```

StyLua に対するさまざまなオプションは、上記のコマンドライン（`--syntax=Lua54` など）か、プロジェクト内の `stylua.toml` で指定できます:

```toml
syntax = "Lua54"
column_width = 100
line_endings = "Unix"
indent_type = "Spaces"
indent_width = 4
quote_style = "AutoPreferDouble"
call_parentheses = "Always"
collapse_simple_statement = "All"

[sort_requires]
enabled = true
```

利用可能なオプションの完全な一覧については: [StyLua Options](https://github.com/JohnnyMorganz/StyLua?tab=readme-ov-file#options) を参照してください。
