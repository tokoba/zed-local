# HTML

HTML のサポートは [HTML extension](https://github.com/zed-industries/zed/tree/main/extensions/html) で利用できます。

- Tree-sitter: [tree-sitter/tree-sitter-html](https://github.com/tree-sitter/tree-sitter-html)
- 言語サーバー: [microsoft/vscode-html-languageservice](https://github.com/microsoft/vscode-html-languageservice)

この拡張機能は自動的にインストールされますが、使用したくない場合は、設定に次の内容を追加できます。

```json [settings]
{
  "auto_install_extensions": {
    "html": false
  }
}
```

## フォーマット

デフォルトでは、Zed は HTML のフォーマットに [Prettier](https://prettier.io/) を使用します。

Settings ({#kb zed::OpenSettings}) の Languages > HTML でフォーマットを設定するか、設定ファイルに次を追加します。

```json [settings]
  "languages": {
    "HTML": {
      "format_on_save": "off",
    }
  }
```

{#kb editor::Format} を使うか、[command palette](..//getting-started.md#command-palette) ({#kb command_palette::Toggle}) を開いて "Format Document" を選択することで、手動でフォーマットを実行することもできます。

### LSP フォーマット

Prettier の代わりに `vscode-html-language-server` 言語サーバーの自動フォーマットを使用するには、Settings ({#kb zed::OpenSettings}) の Languages > HTML でフォーマッタを設定するか、設定ファイルに次を追加します。

```json [settings]
  "languages": {
    "HTML": {
      "formatter": "language_server",
    }
  }
```

Zed の `settings.json` から、`vscode-html-language-server` 用のさまざまな[フォーマットオプション](https://code.visualstudio.com/docs/languages/html#_formatting)をカスタマイズできます。

```json [settings]
  "lsp": {
    "vscode-html-language-server": {
      "settings": {
        "html": {
          "format": {
            // <html> および <head> 内をインデントする (デフォルト: false)
            "indentInnerHtml": true,
            // <svg> や <script> 内のフォーマットを無効にする
            "contentUnformatted": "svg,script",
            // <div> と <p> の前に余分な改行を追加する
            "extraLiners": "div,p"
          }
        }
      }
    }
  }
```

## HTML で Tailwind CSS Language Server を使用する

HTML ファイルで [Tailwind CSS language server](https://github.com/tailwindlabs/tailwindcss-intellisense/tree/HEAD/packages/tailwindcss-language-server#readme) のすべての機能（補完、Lint など）を利用するには、`settings.json` に次を追加して、CSS クラスをどこで探せばよいかを言語サーバーに知らせる必要があります。

```json [settings]
{
  "lsp": {
    "tailwindcss-language-server": {
      "settings": {
        "experimental": {
          "classRegex": ["class=\"([^\"]*)\""]
        }
      }
    }
  }
}
```

これらの設定により、HTML の `class` 属性内で Tailwind CSS クラスの補完が利用できるようになります。例:

```html
<div class="flex items-center <completion here>">
  <p class="text-lg font-bold <completion here>">Hello World</p>
</div>
```
