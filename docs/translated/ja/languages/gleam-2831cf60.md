# Gleam

Gleam のサポートは [Gleam extension](https://github.com/gleam-lang/zed-gleam) を通じて利用できます。Gleam について学ぶには、[docs](https://gleam.run/documentation/) を参照するか、[`stdlib` reference](https://hexdocs.pm/gleam_stdlib/) を確認してください。Gleam language server には、定義へのジャンプ、自動インポートなど、さまざまな機能があります。

- Tree-sitter: [gleam-lang/tree-sitter-gleam](https://github.com/gleam-lang/tree-sitter-gleam)
- Language Server: [gleam lsp](https://github.com/gleam-lang/gleam/tree/main/compiler-core/src/language_server)
