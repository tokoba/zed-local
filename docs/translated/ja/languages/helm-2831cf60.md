# Helm

Zed における Helm のサポートは、コミュニティによってメンテナンスされている [Helm extension](https://github.com/cabrinha/helm.zed) によって提供されています。

- Tree-sitter: [tree-sitter-go-template](https://github.com/ngalaiko/tree-sitter-go-template/tree/master)
- 言語サーバー: [mrjosh/helm-ls](https://github.com/mrjosh/helm-ls)

## セットアップ

`.zed/settings.json` を編集し、次を追加して Helm ファイルに対して Helm 言語を有効にします:

```json [settings]
  "file_types": {
    "Helm": [
      "**/templates/**/*.tpl",
      "**/templates/**/*.yaml",
      "**/templates/**/*.yml",
      "**/helmfile.d/**/*.yaml",
      "**/helmfile.d/**/*.yml",
      "**/values*.yaml"
    ]
  }
```

これにより、helm-ls がこれをサポートしているため、values.yaml ファイルも型 helm としてマークされます。
