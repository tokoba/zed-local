# Rego

Zed における Rego 言語サポートは、コミュニティによってメンテナンスされている [Rego extension](https://github.com/StyraInc/zed-rego) によって提供されています。

- Tree-sitter: [FallenAngel97/tree-sitter-rego](https://github.com/FallenAngel97/tree-sitter-rego)
- 言語サーバー: [open-policy-agent/regal](https://github.com/open-policy-agent/regal)

## インストール

この拡張機能は主に [Regal](https://docs.styra.com/regal/language-server) 言語サーバーに基づいており、拡張機能を利用するにはこれをインストールする必要があります。詳細については、[はじめに](https://docs.styra.com/regal#getting-started) の手順を参照してください。

## 設定

拡張機能の動作は `.regal/config.yaml` ファイルで設定します。以下は、`todo-comment` ルールを無効にし、`line-length` ルールをカスタマイズし、`opa-fmt` ルールに対してテストファイルを無視する例の設定です:

```yaml
rules:
  style:
    todo-comment:
      # TODO コメントについては報告しない
      level: ignore
    line-length:
      # ルールのカスタム設定
      max-line-length: 100
      # 行が長すぎる場合は警告するが、失敗にはしない
      level: warning
    opa-fmt:
      # デフォルトが error なので必須ではないが
      # 明示しておいても問題はない
      level: error
      # 各ルールごとにファイルを無視できる
      # この例ではテストファイルが無視される
      ignore:
        files:
          - "*_test.rego"
```

詳細については Regal の[設定ドキュメント](https://docs.styra.com/regal#configuration) を参照してください。
