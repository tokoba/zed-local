# Luau

[Luau](https://luau.org/) は、Lua をベースにした、高速・小型・安全で、段階的型付けを備えた埋め込み可能なスクリプト言語です。Luau は Roblox によって開発され、MIT ライセンスで提供されています。

Zed における Luau 言語サポートは、コミュニティによってメンテナンスされている [Luau extension](https://github.com/4teapo/zed-luau) によって提供されています。
問題の報告先: <https://github.com/4teapo/zed-luau/issues>

- Tree-sitter: [4teapo/tree-sitter-luau](https://github.com/4teapo/tree-sitter-luau)
- 言語サーバー: [JohnnyMorganz/luau-lsp](https://github.com/JohnnyMorganz/luau-lsp)

## 設定

設定手順は [Luau Zed Extension README](https://github.com/4teapo/zed-luau) に記載されています。

## フォーマット

コードを自動でフォーマットするには、Lua 用コードフォーマッターである [JohnnyMorganz/StyLua](https://github.com/JohnnyMorganz/StyLua) を使用できます。

次のようにインストールします:

```sh
# macOS では Homebrew を使用
brew install stylua
# または Cargo を使用
cargo install stylua --features lua52,lua53,lua54,luau
```

フォーマットの設定は、Settings ({#kb zed::OpenSettings}) の Languages > Luau で行うか、設定ファイルに次を追加してください:

```json [settings]
  "languages": {
    "Luau": {
      "formatter": {
        "external": {
          "command": "stylua",
          "arguments": ["-"]
        }
      }
    }
  }
```
