# ReStructuredText (rst)

Zed における ReStructuredText 言語サポートは、コミュニティによってメンテナンスされている [reST extension](https://github.com/elmarco/zed-rst) によって提供されています。
不具合の報告先: <https://github.com/elmarco/zed-rst/issues>

- Tree-sitter: [stsewd/tree-sitter-rst.git](https://github.com/stsewd/tree-sitter-rst.git)
- 言語サーバー: [swyddfa/esbonio](https://github.com/swyddfa/esbonio)
