# C

Zed には C のサポートがネイティブで用意されています。

- Tree-sitter: [tree-sitter/tree-sitter-c](https://github.com/tree-sitter/tree-sitter-c)
- 言語サーバー: [clangd/clangd](https://github.com/clangd/clangd)
- デバッグアダプター: [CodeLLDB](https://github.com/vadimcn)（プライマリ）、[GDB](https://sourceware.org/gdb/)（セカンダリ、Apple silicon では利用不可）

## Clangd: C として強制認識させる

Clangd は標準では C++/C 混在のプロジェクトを想定しています。C のみのプロジェクトの場合は、すべてのファイルを C として扱うよう `-xc` フラグで clangd に指示したくなるかもしれません。これを行うには、プロジェクトのルートに次の内容の `.clangd` ファイルを作成します。

```yaml
# yaml-language-server: $schema=https://json.schemastore.org/clangd.json
CompileFlags:
  Add: [-xc]
```

デフォルトでは clang と gcc は `*.C` と `*.H`（大文字の拡張子）を C ではなく C++ として認識するため、Zed もこの規約に従います。C のみのプロジェクト（`FILENAME.C` のようなレガシーな大文字パスを持つプロジェクトなど）で作業している場合は、設定に次を追加することでこの挙動を上書きできます。

```json [settings]
{
  "file_types": {
    "C": ["C", "H"]
  }
}
```

## フォーマット

デフォルトでは、Zed は C コードのフォーマットに `clang-format` CLI ツールと同様に `clangd` 言語サーバーを使用します。これを設定するには、`.clang-format` ファイルを追加します。例:

```yaml
# yaml-language-server: $schema=https://json.schemastore.org/clang-format-21.x.json
---
BasedOnStyle: GNU
IndentWidth: 2
---
```

利用可能なオプションの一覧については [Clang-Format Style Options](https://clang.llvm.org/docs/ClangFormatStyleOptions.html) を参照してください。

フォーマットは {#kb editor::Format} か、コマンドパレットから `editor: format` アクションを実行するか、保存時のフォーマットを有効にしてトリガーできます。

設定 ({#kb zed::OpenSettings}) の Languages > C でフォーマットを構成するか、設定ファイルに次を追加します。

```json [settings]
  "languages": {
    "C": {
      "format_on_save": "on",
      "tab_size": 2
    }
  }
```

## コンパイルコマンド

一部のプロジェクトでは、Clangd がプロジェクトを正しく解析するために `compile_commands.json` ファイルを必要とします。このファイルには、プロジェクトのビルド方法を clangd に伝えるコンパイルデータベースが含まれます。

### CMake のコンパイルコマンド

CMake では、`CMakeLists.txt` に次の行を追加することで `compile_commands.json` を自動生成できます。

```cmake
set(CMAKE_EXPORT_COMPILE_COMMANDS ON)
```

プロジェクトをビルドすると、CMake はビルドディレクトリに `compile_commands.json` ファイルを生成し、clangd はそれを自動的に検出します。

## デバッグ

ネイティブバイナリのデバッグには CodeLLDB または GDB を使用できます。（ビルドプロセスで C コンパイラに `-g` オプションを渡し、生成されるバイナリにデバッグ情報が含まれるようにしてください。）`.zed/debug.json` に追加できるデバッグ設定の例を以下に示します。

- [CodeLLDB 構成ドキュメント](https://github.com/vadimcn/codelldb/blob/master/MANUAL.md#starting-a-new-debug-session)
- [GDB 構成ドキュメント](https://sourceware.org/gdb/current/onlinedocs/gdb.html/Debugger-Adapter-Protocol.html)

### バイナリのビルドとデバッグ

```json [debug]
[
  {
    "label": "Debug native binary",
    "build": {
      "command": "make",
      "args": ["-j8"],
      "cwd": "$ZED_WORKTREE_ROOT"
    },
    "program": "$ZED_WORKTREE_ROOT/build/prog",
    "request": "launch",
    "adapter": "CodeLLDB"
  }
]
```
