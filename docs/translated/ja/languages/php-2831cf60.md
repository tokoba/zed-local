# PHP

PHP のサポートは [PHP extension](https://github.com/zed-extensions/php) を通じて利用できます。

- Tree-sitter: [tree-sitter/tree-sitter-php](https://github.com/tree-sitter/tree-sitter-php)
- 言語サーバー: [phpactor/phpactor](https://github.com/phpactor/phpactor)
- 代替言語サーバー: [bmewburn/vscode-intelephense](https://github.com/bmewburn/vscode-intelephense/)

## PHP のインストール

PHP 拡張機能を使用するには、PHP がインストールされていて `PATH` から利用できる必要があります:

```sh
# macOS（Homebrew 経由）
brew install php

# Debian/Ubuntu
sudo apt-get install php-cli

# CentOS 8+/RHEL
sudo dnf install php-cli

# Arch Linux
sudo pacman -S php

# PHP のパスを確認
## macOS と Linux
which php

## Windows
where php
```

## 言語サーバーの選択

PHP 拡張機能は [LSP 言語サーバー](https://microsoft.github.io/language-server-protocol) を使用しており、デフォルトは Phpactor です。Zed がサポートする別の言語サーバー（例: Intelephense や PHP Tools）を使用したい場合は、その実装方法についてドキュメントに必ず従ってください。

### Intelephense

[Intelephense](https://intelephense.com/) は、フリーミアムモデルで提供される PHP 用の[プロプライエタリ](https://github.com/bmewburn/vscode-intelephense/blob/master/LICENSE.txt#L29)な言語サーバーです。一部の機能を利用するには [プレミアムライセンス](https://intelephense.com/buy) の購入が必要です。

言語サーバーは、Settings ({#kb zed::OpenSettings}) の Languages > PHP で設定するか、設定ファイルに次の内容を追加して設定します:

```json [settings]
{
  "languages": {
    "PHP": {
      "language_servers": ["intelephense", "!phpactor", "!phptools", "..."]
    }
  }
}
```

プレミアム機能を利用するには、macOS および Linux の場合はホームディレクトリ内の `~/intelephense/licence.txt` に、Windows の場合は `%USERPROFILE%/intelephense/licence.txt` にライセンスファイルを配置できます。

または、初期化オプションとしてライセンスキー、もしくはライセンスキーを含むファイルへのパスを渡すこともできます。その場合は、`settings.json` に次の設定を追加します:

```json [settings]
{
  "lsp": {
    "intelephense": {
      "initialization_options": {
        "licenceKey": "/path/to/licence.txt"
      }
    }
  }
}
```

### PHP Tools

[PHP Tools](https://www.devsense.com/) は、無料機能とプレミアム機能を提供するプロプライエタリな言語サーバーです。プレミアム機能を有効化するには、[ライセンスを購入](https://www.devsense.com/en/purchase) する必要があります。

言語サーバーは、Settings ({#kb zed::OpenSettings}) の Languages > PHP で設定するか、設定ファイルに次の内容を追加して設定します:

```json [settings]
{
  "languages": {
    "PHP": {
      "language_servers": ["phptools", "!intelephense", "!phpactor", "..."]
    }
  }
}
```

プレミアム機能を利用するには、`settings.json` の `initialization_options` にライセンスを追加できます:

```json [settings]
{
  "lsp": {
    "phptools": {
      "initialization_options": {
        "0": "your_license_key"
      }
    }
  }
}
```

または、プロジェクトの `.env` ファイルで環境変数 `DEVSENSE_PHP_LS_LICENSE` を設定します。

```env
DEVSENSE_PHP_LS_LICENSE="your_license_key"
```

詳細については [PHP Tools for Zed](https://docs.devsense.com/other/zed/) のドキュメントを参照してください。

## デバッグ

PHP 拡張機能は、Xdebug を介して PHP 用のデバッグアダプターを提供します。利用方法はいくつかあります:

```json
[
  {
    "label": "PHP: Listen to Xdebug",
    "adapter": "Xdebug",
    "request": "launch",
    "port": 9003
  },
  {
    "label": "PHP: Debug this test",
    "adapter": "Xdebug",
    "request": "launch",
    "program": "vendor/bin/phpunit",
    "args": ["--filter", "$ZED_SYMBOL"]
  }
]
```

問題が発生した場合の一般的なトラブルシューティングのヒントは次のとおりです:

- 使用中の PHP のバージョンに対応した Xdebug がインストールされていることを確認してください。
- `debug` モードで動作するように Xdebug が設定されていることを確認してください。
- Xdebug が実際にデバッグセッションを開始していることを確認してください。
- Xdebug と Zed の間でホスト名とポート番号が一致していることを確認してください。
- デバッグしようとしているページで `xdebug_info()` 関数を使用して、診断ログを確認してください。

## PHP で Tailwind CSS Language Server を使用する

PHP ファイルで [Tailwind CSS language server](https://github.com/tailwindlabs/tailwindcss-intellisense/tree/HEAD/packages/tailwindcss-language-server#readme) のすべての機能（補完、Lint など）を利用するには、`settings.json` に次の設定を追加して、CSS クラスをどこから検出するかを言語サーバーに認識させる必要があります:

```json [settings]
{
  "lsp": {
    "tailwindcss-language-server": {
      "settings": {
        "includeLanguages": {
          "php": "html"
        },
        "experimental": {
          "classRegex": [
            "class=\"([^\"]*)\"",
            "class='([^']*)'",
            "class=\\\"([^\\\"]*)\\\""
          ]
        }
      }
    }
  }
}
```

これらの設定により、PHP ファイル内の HTML 属性で Tailwind CSS クラスの補完が得られます。例:

```php
<?php
// HTML を含む PHP ファイル:
?>
<div class="flex items-center <completion here>">
  <p class="text-lg font-bold <completion here>">Hello World</p>
</div>
```

### Laravel/Blade

Laravel/Blade ファイルでは、Blade ディレクティブを扱うために追加の設定が必要になる場合があります:

```json [settings]
{
  "lsp": {
    "tailwindcss-language-server": {
      "settings": {
        "includeLanguages": {
          "php": "html",
          "blade": "html"
        },
        "experimental": {
          "classRegex": [
            "class=\"([^\"]*)\"",
            "class='([^']*)'",
            "class=\\\"([^\\\"]*)\\\"",
            "@class\\(\\[([^\\]]*)\\]\\)"
          ]
        }
      }
    }
  }
}
```

これにより、次のような Blade ディレクティブ内でも補完が行われます:

```blade
{{-- Blade ファイル --}}
<div class="flex {{ $customClass }} <completion here>">
  @class(['flex', 'items-center', '<completion here>'])
</div>
```
