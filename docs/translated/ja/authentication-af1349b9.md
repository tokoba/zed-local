# Zed で認証する

Zed にサインインする必要はありません。コードエディタに期待されるほとんどの機能は、サインインせずに利用できます。ここでは、サインインが必要となる一部の機能と、その方法について説明します。

## サインインが必要な機能

1. すべてのリアルタイム[コラボレーション機能](./collaboration/overview.md)。
2. LLM モデルのプロバイダとして Zed を使用している場合の [LLM を利用した機能](./ai/overview.md)。サインインせずに AI を利用するには、[自身の API キーを持ち込み、設定](./ai/llm-providers.md#use-your-own-keys)することができます。

## サインイン

Zed は GitHub の OAuth フローを使用してユーザーを認証しており、`read:user` GitHub スコープのみを要求します。このスコープは、あなたの GitHub プロフィール情報への読み取り専用アクセスを許可します。

1. Zed を開き、ウィンドウ右上の `Sign In` ボタンをクリックするか、コマンドパレット（macOS では `cmd-shift-p`、Windows/Linux では `ctrl-shift-p`）から `client: sign in` コマンドを実行します。
2. 既定の Web ブラウザで Zed のサインインページが開きます。
3. 指示に従い、GitHub アカウントで認証します。
4. 認証が成功すると、ブラウザに確認画面が表示され、自動的に Zed にサインインされます。

**注意**: 企業のファイアウォールの内側にいる場合は、`zed.dev` と `collab.zed.dev` への接続が許可されていることを確認してください。

## サインアウト

Zed からサインアウトするには、次のいずれかの方法を使用できます。

- 右上のプロファイルアイコンをクリックし、ドロップダウンメニューから `Sign Out` を選択します。
- コマンドパレットを開き、`client: sign out` コマンドを実行します。

## メールアドレス {#email}

Zed アカウントのメールアドレスは、GitHub OAuth によって提供されるアドレスです。公開メールアドレスがある場合はそれが使用され、ない場合はプライマリの GitHub メールアドレスが使用されます。GitHub 上でメールアドレスを変更した場合は、[zed.dev にサインイン](https://zed.dev/sign_in)することで Zed アカウントに同期できます。

課金には Stripe を使用しており、サブスクリプション開始時には Zed アカウントのメールアドレスを利用します。現在のところ、Zed アカウントのメールアドレスを変更しても、Stripe で使用されるメールアドレスは更新されません。このメールアドレスの変更方法については、[請求情報の更新](./ai/billing.md#updating-billing-info)を参照してください。

## インターフェースから Sign In ボタンを非表示にする

Sign In 機能を使用しない場合は、設定プロパティ `show_sign_in` を使用して、インターフェースからそれを非表示にすることができます。詳細については [Visual Customization ページ](./visual-customization.md)を参照してください。
