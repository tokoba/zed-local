# ロール

Zed 組織の各メンバーにはロールが割り当てられ、それによってアクセスおよび設定できる内容が決まります。

## ロールの種類 {#roles}

組織の各メンバーには、次の 3 つのいずれかのロールが割り当てられます:

| ロール     | 説明                                                |
| ---------- | --------------------------------------------------- |
| **Owner**  | 請求および所有権の移転を含むすべての操作が可能      |
| **Admin**  | 請求関連を除くすべての操作が可能                    |
| **Member** | 標準的なアクセスのみで、特権的な操作は不可          |

### Owner {#role-owner}

Owner は組織に対して、次のような完全な管理権限を持ちます:

- メンバーを招待および削除する
- メンバーのロールを割り当ておよび変更する
- 請求、支払方法、請求書を管理する
- データ共有ポリシーを設定する
- Zed の共同作業機能を無効化する
- メンバーが Zed-hosted モデルおよび Zed の編集予測を利用できるかどうかを制御する
- 所有権を別のメンバーに移転する

### Admin {#role-admin}

Admin は Owner と同じ機能を持ちますが、次のことはできません:

- 請求設定へアクセスしたり変更したりする
- 組織の所有権を移転する

このロールは、支払いの詳細を確認する必要はないものの、日々のメンバーアクセスを管理するチームリードやマネージャーに適しています。

### Member {#role-member}

Member は Zed への標準的なアクセス権を持ちます。請求や組織設定にはアクセスできません。

## ユーザーロールの管理 {#managing-users}

Owner と Admin は、Zed ダッシュボードの Members ページから組織のメンバーを管理できます。

### メンバーの招待 {#inviting-members}

1. Members ページで **+ Invite Member** を選択します。
2. メンバーの会社のメールアドレスを入力し、ロールを選択します。
3. 招待されたユーザーには、参加手順が記載されたメールが送信されます。承諾後、GitHub を通じて認証を行います。

### メンバーのロール変更 {#changing-roles}

1. Members ページで対象のメンバーを探します。ロールでフィルタするか、名前で検索できます。
2. 3 点メニューを開き、新しいロールを選択します。

### メンバーの削除 {#removing-members}

1. Members ページで対象のメンバーを探します。
2. **Remove** を選択し、確認します。

メンバーを削除すると、そのメンバーは組織設定および組織によって管理される機能へのアクセス権を失います。なお、そのメンバーは個人として Zed を使い続けることができます。
