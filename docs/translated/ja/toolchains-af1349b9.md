# ツールチェーン

Zed プロジェクトには、現在のプロジェクト内で各言語に対して使用するツールを選択できるツールチェーンセレクターが用意されています。

たとえば Python プロジェクトでは、仮想環境が依存関係やインタープリタのパスを定義します。言語サーバーはコードを正しく解析するために、その環境を必要とします。
ツールチェーンセレクターを使えば、言語サーバーのパスを手動で設定する代わりに、ドロップダウンから適切な仮想環境を選択できます。

Zed プロジェクト内の異なるサブプロジェクトごとに、異なるツールチェーンを選択することもできます。サブプロジェクトの定義は言語ごとに異なります。
コラボレーションのシナリオでは、アクティブなツールチェーンを表示・変更できるのはプロジェクトの所有者だけです。

[リモートプロジェクト](./remote-development.md)では、ツールチェーンセレクターを使用して SSH ホスト上のアクティブなツールチェーンを制御できます。[プロジェクトを共有する](./collaboration/overview.md)場合、ツールチェーンセレクターはゲストには利用できません。

## なぜツールチェーンが必要なのですか？

アクティブなツールチェーンは、言語サーバーを起動する際に使用されます。適切なツールチェーンがないと、言語サーバーが依存関係を解決できず、"Go to Definition" や "Code Completions" といった機能が動作しない場合があります。

アクティブなツールチェーンは、ターミナルパネルでシェルを起動する場合にも関係します。一部のツールチェーンはシェル用の「アクティベーションスクリプト」を提供しており、これによってツールチェーンがシェル環境で利用可能になります。新しいターミナルを作成すると、Zed はこれらのアクティベーションスクリプトを自動的に実行します。

これは[タスク](./tasks.md)にも当てはまります。Zed は、あたかも新しいターミナルタブを開いて自分でタスクのコマンドを実行したかのようにタスクを実行するため、タスクの実行もアクティブなツールチェーンとそのアクティベーションスクリプトの影響を受けます。

## ツールチェーンの選択

アクティブなツールチェーン（存在する場合）は、右側のステータスバーに表示されます。そこをクリックしてツールチェーンセレクターを開くか、コマンドパレットのアクション（{#action toolchain::Select}）を実行してください。

Zed は、作業しているプロジェクトに基づいて、選択可能なツールチェーンのセットを自動的に推論します。プロジェクトを初めて開いたときには、ベストエフォートでデフォルトのツールチェーンも自動的に選択されます。

ツールチェーンの選択は現在のサブプロジェクトに対して適用されます。サブプロジェクトはプロジェクト全体の場合もあれば、その一部だけの場合もあります。例えばモノレポでは、サブプロジェクトごとに異なるツールチェーンを選択することができます。

## ツールチェーンを手動で追加する

自動検出だけでは不十分な場合は、ツールチェーンを手動で追加できます。そのためには、ツールチェーンセレクター内の "Add toolchain" ボタンをクリックします。そこで、ツールチェーンへのパスを指定し、それに好きな名前を付けることができます。
