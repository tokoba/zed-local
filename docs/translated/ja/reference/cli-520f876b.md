# CLI リファレンス

Zed のコマンドラインインターフェイス (CLI) を使用して、ファイルやディレクトリを開いたり、他のツールと統合したり、スクリプトから Zed を制御したりできます。

## インストール

**macOS:** コマンドパレット ({#kb command_palette::Toggle}) から `cli: install` コマンドを実行して、`zed` CLI を `/usr/local/bin/zed` にインストールします。

**Linux:** CLI は Zed パッケージに同梱されています。バイナリ名はディストリビューションによって異なる場合があります (一般的には `zed` または `zeditor`)。

**Windows:** CLI は Zed に同梱されています。Zed のインストールディレクトリを PATH に追加するか、`zed.exe` へのフルパスを使用します。

## 使用方法

```sh
zed [OPTIONS] [PATHS]...
```

## ファイルとディレクトリを開く

ファイルを開く:

```sh
zed myfile.txt
```

ディレクトリをワークスペースとして開く:

```sh
zed ~/projects/myproject
```

複数のファイルやディレクトリを開く:

```sh
zed file1.txt file2.txt ~/projects/myproject
```

特定の行・列でファイルを開く:

```sh
zed myfile.txt:42        # 42 行目で開く
zed myfile.txt:42:10     # 42 行目 10 列目で開く
```

## オプション

### `-w`, `--wait`

開かれたすべてのファイルが閉じられるまで、CLI の終了を待機します。ディレクトリを開く場合は、そのウィンドウが閉じられるまで待機します。

これは、編集が完了するまでエディタがブロックすることを想定しているツール (例: `git commit`) と Zed を統合する場合に便利です:

```sh
export EDITOR="zed --wait"
git commit  # Zed を開き、コミットメッセージファイルを閉じるまで待機する
```

### `-n`, `--new`

パスが既存のウィンドウで既に開かれている場合でも、新しいワークスペースウィンドウでパスを開きます:

```sh
zed -n ~/projects/myproject
```

### `-a`, `--add`

新しいウィンドウを開くのではなく、現在フォーカスされているワークスペースにパスを追加します。複数のワークスペースウィンドウが開かれている場合、ファイルはフォーカスされているウィンドウで開かれます:

```sh
zed -a newfile.txt
```

### `-r`, `--reuse`

既存のウィンドウを再利用し、その現在のワークスペースを新しいパスで置き換えます:

```sh
zed -r ~/projects/different-project
```

### `--diff <OLD_PATH> <NEW_PATH>`

2 つのファイルを比較する diff ビューを開きます。複数回指定できます:

```sh
zed --diff file1.txt file2.txt
zed --diff old.rs new.rs --diff old2.rs new2.rs
```

### `--foreground`

Zed をフォアグラウンドで実行し、ターミナルを接続したままにします。デバッグに便利です:

```sh
zed --foreground
```

### `--user-data-dir <DIR>`

デフォルトの場所の代わりに、すべてのユーザーデータ (データベース、拡張機能、ログ) に使用するカスタムディレクトリを指定します:

```sh
zed --user-data-dir ~/.zed-custom
```

デフォルトの場所:

- **macOS:** `~/Library/Application Support/Zed`
- **Linux:** `$XDG_DATA_HOME/zed` (通常は `~/.local/share/zed`)
- **Windows:** `%LOCALAPPDATA%\Zed`

### `-v`, `--version`

Zed のバージョンを表示して終了します:

```sh
zed --version
```

### `--uninstall`

Zed をアンインストールし、関連するファイルをすべて削除します (macOS および Linux のみ):

```sh
zed --uninstall
```

### `--zed <PATH>`

Zed アプリケーションまたはバイナリへのカスタムパスを指定します:

```sh
zed --zed /path/to/Zed.app myfile.txt
```

## 標準入力から読み込む

パスとして `-` を渡すことで、stdin から内容を読み込みます:

```sh
echo "Hello, World!" | zed -
cat myfile.txt | zed -
ps aux | zed -
```

これにより、stdin の内容を含む一時ファイルが作成され、それが Zed で開かれます。

## URL の取り扱い

CLI は `zed://`、`http://`、`https://` の URL を開くことができます:

```sh
zed zed://settings
zed https://github.com/zed-industries/zed
```

## Zed をデフォルトエディタとして使用する

Git やその他のツールのデフォルトエディタとして Zed を設定します:

```sh
export EDITOR="zed --wait"
export VISUAL="zed --wait"
```

これらの行をシェルの設定ファイル (例: `~/.bashrc`, `~/.zshrc`) に追加します。

## macOS: リリースチャネルの切り替え

macOS では、チャネル名を最初の引数として渡すことで、特定のリリースチャネルを起動できます:

```sh
zed --stable myfile.txt
zed --preview myfile.txt
zed --nightly myfile.txt
```

## WSL 連携 (Windows)

Windows では、CLI は WSL ディストリビューションからのパスを開くことをサポートしています。これは、WSL 内から Zed を起動すると自動的に処理されます。

## 終了コード

| Code | Meaning                                  |
| ---- | ---------------------------------------- |
| `0`  | 成功                                     |
| `1`  | エラー (詳細は stderr に出力されます)   |

`--wait` を使用している場合、終了コードはファイルが閉じられる前に保存されたかどうかを反映します。
