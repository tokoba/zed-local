# スニペット

拡張機能は、1つ以上の言語向けのスニペットを提供できます。

スニペットを含む各ファイルは、`extensions.toml` ファイルの `snippets` フィールドで指定できます。

参照されるパスは `extension.toml` からの相対パスでなければなりません。

## スニペットの定義

ある拡張機能は 1 つ以上のスニペットを提供できます。各スニペットは `extension.toml` に登録されている必要があります。

Zed は言語名の小文字表記に基づいてスニペットファイルを対応付けます（例: Rust には `rust.json`）。  
現在のバッファの言語に関係なく利用可能なスニペットを定義するには、ファイル名として `snippets.json` を使用できます。

例えば、次の拡張機能は Rust と TypeScript 向けのスニペットを提供します:

```toml
snippets = ["./snippets/rust.json", "./snippets/typescript.json"]
```

スニペットの作成方法の詳細については、[スニペットのドキュメント](../snippets.md) を参照してください。
