# コードの編集

Zed は、コードを効率的に記述・変更するためのツールを提供します。このセクションでは、言語サーバーと連携して動作するコアな編集機能について説明します。

## このセクションの内容

- **[コード補完](./completions.md)** — 言語サーバーによる自動補完と、AI を活用した編集予測
- **[スニペット](./snippets.md)** — タブストップ付きの再利用可能なコードテンプレートを挿入
- **[フォーマットと Lint](./configuring-languages.md#formatting-and-linting)** — 自動コードフォーマットと linter 連携を設定
- **[診断とクイックフィックス](./diagnostics.md)** — エラーや警告を表示し、言語サーバーからの修正を適用
- **[Multibuffers](./multibuffers.md)** — 複数カーソルを使って複数ファイルを同時に編集

## これらの機能の連携

コードを編集しているとき、Zed は複数のソースからの入力を組み合わせて利用します。

1. **言語サーバー** は、プロジェクトの型や構造に基づいてコード補完、診断、クイックフィックスを提供します
2. **編集予測** は、入力中に複数文字または複数行にわたる変更を提案します
3. **Multibuffers** によって、複数ファイルにまたがる変更を 1 回の操作で適用できます

例えば、次のように利用できます。

- 言語サーバーのリネームリファクタリングを使って関数名を変更する
- 影響を受けるすべてのファイルを表示する multibuffer で結果を確認する
- 複数カーソルを使ってすべての箇所に追加の編集を行う
- 何かが壊れた場合は、すぐに診断フィードバックを受け取る
