# アンインストール

このガイドでは、さまざまなオペレーティングシステムで Zed をアンインストールする方法を説明します。

## macOS

### 標準インストール

ウェブサイトからダウンロードして Zed をインストールした場合:

1. Zed が実行中であれば終了する
2. Finder を開き、「アプリケーション」フォルダを開く
3. Zed をゴミ箱にドラッグする（または右クリックして「ゴミ箱に入れる」を選択する）
4. ゴミ箱を空にする

### Homebrew インストール

Homebrew を使用して Zed をインストールした場合は、次のコマンドを使用します:

```sh
brew uninstall --cask zed
```

プレビュー版の場合は次のコマンドを実行します:

```sh
brew uninstall --cask zed@preview
```

### ユーザーデータの削除（オプション）

すべての Zed 設定ファイルとデータを完全に削除するには、次の操作を行います:

1. Finder を開く
2. `Cmd + Shift + G` を押して「フォルダへ移動」を開く
3. 以下のディレクトリが存在する場合は削除します:
   - `~/Library/Application Support/Zed`
   - `~/Library/Saved Application State/dev.zed.Zed.savedState`
   - `~/Library/Logs/Zed`
   - `~/Library/Caches/dev.zed.Zed`
   - `~/Library/Caches/Zed`
   - `~/.config/zed`
   - `~/.local/state/Zed`

## Linux

### 標準的なアンインストール

Zed をデフォルトのインストールスクリプトでインストールした場合は、次を実行します:

```sh
zed --uninstall
```

設定を保持するか削除するか確認するメッセージが表示されます。選択後、Zed が正常にアンインストールされたことを示すメッセージが表示されます。

PATH に `zed` コマンドが見つからない場合は、次を試してください:

```sh
$HOME/.local/bin/zed --uninstall
```

または:

```sh
$HOME/.local/zed.app/bin/zed --uninstall
```

### パッケージマネージャー

Flatpak、Snap、ディストリビューション固有のパッケージマネージャーなどを使用して Zed をインストールした場合は、そのパッケージマネージャーのドキュメントを参照してアンインストール手順を確認してください。

### 手動での削除

アンインストールコマンドが失敗した場合や、Zed をカスタムパスにインストールした場合は、次のものを手動で削除できます:

- インストールディレクトリ: `~/.local/zed.app`（またはカスタムインストールパス）
- バイナリへのシンボリックリンク: `~/.local/bin/zed`
- 設定およびデータ: `~/.config/zed`

## Windows

### 標準インストール

1. Zed が実行中であれば終了する
2. 設定を開く（Windows キー + I）
3. 「アプリ」 > 「インストール済みのアプリ」に移動する（Windows 10 の場合は「アプリと機能」）
4. 「Zed」を検索する
5. Zed の横の三点リーダーメニューをクリックし、「アンインストール」を選択する
6. 画面の指示に従ってアンインストールを完了する

別の方法として、次の手順でも実行できます:

1. スタートメニューを開く
2. Zed を右クリックする
3. 「アンインストール」を選択する

### ユーザーデータの削除（オプション）

すべての Zed 設定ファイルとデータを完全に削除するには、次の操作を行います:

1. `Windows キー + R` を押して「ファイル名を指定して実行」を開く
2. `%APPDATA%` と入力して Enter キーを押す
3. `Zed` フォルダーが存在する場合は削除する
4. 再度 `Windows キー + R` を押し、`%LOCALAPPDATA%` と入力して Enter キーを押す
5. `Zed` フォルダーが存在する場合は削除する

## トラブルシューティング

アンインストール中に問題が発生した場合:

- **macOS/Windows**: アンインストールを試みる前に、Zed が完全に終了していることを確認してください。Zed のプロセスが実行中でないか、Activity Manager（macOS）または Task Manager（Windows）を確認します。
- **Linux**: アンインストールスクリプトが失敗した場合は、エラーメッセージを確認し、上記のディレクトリを手動で削除することを検討してください。
- **すべてのプラットフォーム**: Zed をインストールしたままクリーンな状態からやり直したい場合は、アプリケーションを完全にアンインストールする代わりに、設定ディレクトリを削除できます。

さらに詳しいヘルプについては、[Linux 向けのドキュメント](./linux.md) を参照するか、[Zed コミュニティ](https://zed.dev/community-links) をご覧ください。
